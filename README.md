# הבילתיס' — אתר הלהקה

עמוד אחד גולל, עברית RTL.
שפה עיצובית: **"ברק על נייר"** — ארבעה צבעים, חיתוכים אלכסוניים בין מקטעים, צילומים בדואוטון.
HTML/CSS/JS סטטי בלבד. בלי בילד, בלי תלויות, בלי שרת.

## איך מעדכנים תוכן

**כל התוכן יושב בקובץ אחד: `assets/js/data.js`.**

| מה לשנות | איפה ב-`data.js` |
|---|---|
| שם, סלוגן, שורת פתיחה | `bandName`, `tagline`, `kicker` |
| האמנים שבפס הרץ | `acts` |
| טקסט האודות + שלוש הנקודות | `about` |
| נגנים | `members` |
| הופעות | `shows` |
| סרטונים | `videos` |
| תמונות גלריה | `gallery` |
| מייל, טלפון, רשתות | `contact` |

### הופעות
```js
{ date: "2026-11-14", time: "21:00", title: "הבילתיס'",
  venue: "לבונטין 7", city: "תל אביב", tickets: "https://..." }
```
- `date` תמיד `YYYY-MM-DD`.
- האתר ממיין ומפריד לבד בין עתיד לעבר. אין צורך למחוק הופעות שעברו.
- `tickets: null` → מוצג `note` (למשל "כניסה חופשית"), ואם אין `note` — "פרטים בקרוב".
- כשההופעה היא פשוט הלהקה (`title` זהה ל-`bandName`), שם המקום הופך לכותרת השורה.
- רשימה ריקה `[]` → מוצג בלוק "התאריכים הבאים בדרך" עם כפתור להזמנת הופעה.

### סרטונים
`youtube` = המזהה בלבד. מתוך `youtube.com/shorts/45p1edzBxQM` → `"45p1edzBxQM"`.
`aspect: "9/16"` לריל אנכי (ברירת מחדל `"16/9"`). הלייטבוקס מתאים את עצמו.

## צבעים

ארבעה צבעים, כולם ב-`assets/css/style.css` בראש הקובץ:

```css
--ink:     #15120F;   /* פחם חם — רקע ראשי */
--cream:   #F5ECD9;   /* נייר — מקטע אודות */
--mustard: #E9B23C;   /* חרדל — מקטע הופעות, דואוטון הנגנים */
--red:     #D7261A;   /* אדום — מקטע קשר, כפתורים, פס רץ */
```

כל מקטע הוא שטח צבע מלא, והמעבר ביניהם הוא חיתוך אלכסוני (`--slant`).
הצבעים נגזרו מהלוגו ומפלייר ההזמנות הקיימים.

## פונטים

- **Karantina** — כותרות. סאנס עברי דחוס, אנרגיית פוסטר.
- **Rubik** — גוף הטקסט וממשק. סאנס גיאומטרי.

## דואוטון

כל צילום בדואוטון מתבצע ב-CSS בלבד, בלי לערוך את הקבצים:
`.duo--ink` (פחם/שמנת), `.duo--mustard` (חרדל/חום), `.duo--red` (hover על נגן).
להחלפת תמונה — פשוט לדרוס את הקובץ ב-`images/`. האתר עושה את שאר העבודה.

| סוג | יחס | גודל |
|---|---|---|
| `hero.jpg` | 16:9 | 2400×1350 |
| `member-*.jpg` | 3:4 | 1000×1333 |
| `gallery-*.jpg` | כל יחס | רוחב ~1600 |
| `video-1.jpg` | 16:9 | 1600×900 |

## נגישות ופרטים טכניים

- `prefers-reduced-motion` מכובד — הגרעין, הפס הרץ וכל האנימציות נכבים.
- גלריה ווידאו בלייטבוקס עם ניווט מקלדת. ב-RTL: חץ ימינה = אחורה.
- יוטיוב נטען דרך `youtube-nocookie.com`.
- אין מעקב ואין עוגיות. התלות החיצונית היחידה היא Google Fonts.
